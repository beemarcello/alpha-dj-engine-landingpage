Analysis

Track analysis

Available Since 1.0.0 macOS

Track analysis interprets each of the DJ's own audio files locally and reads its BPM, musical key (as a Camelot value), energy and loudness, so Alpha can sequence and level the set. Track analysis is the first step, labelled 01 Analyze.

What Track analysis does

Track analysis reads the selected audio files on the DJ's own computer and detects, per track, the BPM (tempo), the musical key expressed on the Camelot wheel, an energy value used to shape the set, and the loudness (LUFS) and true peak used by Match loudness. Track analysis runs entirely on the DJ's machine; the audio never leaves the computer. Nothing is written to the USB stick during this step. When analysis finishes, the DJ continues to the Composer.

How to use Track analysis

  1. Add tracks or a folder in the Source / tracks to analyze box (see Track selection).
  2. Choose the target USB drive in the USB drive / target device box.
  3. Click Analyze.
  4. When the count under ANALYZED is complete, click Open Composer to build the set.

What Track analysis does not do

  • Track analysis does not upload the DJ's audio anywhere. Analysis happens locally on the DJ's computer.
  • Track analysis does not write anything to the USB stick. Writing happens only in the Export step.
  • Track analysis does not change the DJ's audio files; it only reads them.
  • Track analysis does not need an internet connection to read BPM, key, energy and loudness.

Common questions about Track analysis

Does Track analysis upload my music?
No. Track analysis runs on the DJ's own computer and the audio files never leave the machine.
Does Track analysis change or move my files?
No. Track analysis only reads the files to detect BPM, key, energy and loudness. The files are not changed, and nothing is written to the USB stick in this step.
The detected key or BPM looks wrong — why?
Key and tempo detection is automatic and can occasionally differ from the DJ's own value, especially for tracks with an ambiguous key. The value is a starting point for sequencing.

Track selection

Available Since 1.0.0 macOS

Track selection lets the DJ build the list of tracks to analyze from whole folders and from individually picked files across several folders, collected in a staging list before analysis starts.

What Track selection does

Track selection gathers the files the DJ wants in the set. The DJ can add every track from a folder, or pick individual tracks from different folders, and all chosen tracks appear in a scrollable staging list in the Source / tracks to analyze box. Tracks can be removed one by one or all at once before analysis.

How to use Track selection

  1. Click + Folder to add every track from a folder.
  2. Click + Tracks to pick individual files (multiple can be selected at once); repeat from other folders as needed.
  3. Review the staging list; remove a single track with its remove control, or use Clear to empty the list.
  4. Click Analyze to interpret the staged tracks.

rekordbox import

Available Since 1.0.0 macOS

rekordbox import reads a rekordbox XML export and reuses its BPM, key and beatgrid, so those are not analyzed again. After the import the DJ chooses one of two ways to continue: pick a set of tracks from the library, or write the whole library straight to the USB stick.

What rekordbox import does

rekordbox import loads the tracks from a rekordbox XML file, matches them to the DJ's files on disk, and keeps the BPM, key and beatgrid that rekordbox already worked out — none of that is analyzed again. Tracks whose files cannot be found on disk are reported as missing and skipped. Because a set is a curated selection, the import does not drop a whole library into the Composer; instead it offers two paths: Pick tracks for a set, which opens a filterable browser to choose the tracks for one set, or Write whole library to USB, which skips composing and writes every imported track to the stick in Denon Engine format. Energy (needed for the Composer's arc) is the one value not in the XML; it is computed only for the tracks the DJ actually picks, and not at all for the whole-library write.

How to use rekordbox import

  1. In rekordbox, export your collection (or a playlist) as an XML file.
  2. In the Analyze step, click + XML and choose that XML file.
  3. Read the summary: how many tracks were found and how many are missing, with the coverage for BPM, key, duration, energy and loudness.
  4. To build one set, click Pick tracks for a set, filter by search, key, genre or BPM range, tick the tracks you want, then click Add 0 → Compose (the number is how many are selected). Energy is computed for the picked tracks and the Composer opens.
  5. To transfer everything as-is, click Write whole library to USB; the Export step opens with every imported track ready to write.

What rekordbox import does not do

  • rekordbox import does not re-analyze BPM, key or beatgrid; it trusts the values from rekordbox.
  • rekordbox import does not import cue points from the XML.
  • rekordbox import does not copy files at import time; files are copied only when the set or library is written in Export.
  • The whole-library path does not compute energy and does not build an arc; it writes the tracks in the imported order.
  • rekordbox import does not change the DJ's rekordbox library or the XML file.

Common questions about rekordbox import

My library has over a thousand tracks — do they all go into the Composer?
No. A set is a selection, so the import asks how to continue. Use Pick tracks for a set to filter and choose the tracks for one set, or Write whole library to USB to transfer everything without composing.
Why are some tracks reported as missing?
Those files could not be found on disk at the paths stored in the XML (moved or renamed since the export). They are skipped; the found tracks import normally.
Do I lose my BPM and key by importing?
No. The BPM, key and beatgrid from rekordbox are kept as-is; only energy (and, if needed, loudness) is computed, and only for the tracks you pick.
Can I match loudness on an imported library?
Yes, but the loudness is not in the XML, so it is measured first. See Match loudness — the Export checkbox is locked until the loudness is measured, and clicking it offers to measure and match right away.

Sequencing

Compose

Available Since 1.0.0 macOS

Compose builds an ordered set from the analyzed tracks: the DJ draws an energy arc, sets the length, and chooses how strongly to favour harmonic mixing, then Alpha generates a sequence that follows the arc. Compose is the second step, labelled 02 Compose.

What Compose does

Compose orders the analyzed tracks into a set. The DJ picks an energy arc template and can drag its points to shape the curve, sets the target length, and adjusts two priorities. Compose then generates a track order that follows the drawn energy arc and mixes harmonically according to those priorities. The result is opened in the Refine step for review.

How to use Compose

  1. Pick an energy arc template (Journey, Wave, Build, Peak-time, Cooldown) and drag its points to shape the curve.
  2. Set the length with the minus/plus controls, or click Fit all tracks to size it to all imported tracks.
  3. Set the two priority sliders (harmonic vs. energy arc, and key vs. BPM).
  4. Click Generate to build the ordered set.

Common questions about Compose

What does the energy arc do?
The energy arc is the shape the set follows over time. Compose orders the tracks so their energy rises and falls along the curve the DJ draws.
Should I favour harmonic or energy arc?
Pull toward Harmonic for the smoothest key transitions; pull toward Energy arc to follow the drawn curve more closely, even if some key changes are rougher.
Can I change the order after generating?
Yes. The generated order opens in the Refine step, where individual tracks can be reordered or removed.

Refine

Available Since 1.0.0 macOS

Refine is where the DJ reviews the generated set: audition each track in a mini-player, drag tracks to reorder them, and remove tracks that do not fit. Refine is the third step, labelled 03 Refine.

What Refine does

Refine shows the generated set as a row of energy bars with a mini-player. The DJ can click a bar to load that track, play it, drag a bar to move a track to a new position, and delete a track that does not belong. The Refine step also carries the Match loudness control (documented separately). When the set is ready, the DJ sends it to Export.

How to use Refine

  1. Click a bar to select and load that track into the mini-player.
  2. Press play to audition it; drag the progress bar to scrub.
  3. Drag a bar left or right to reorder that track in the set.
  4. Use the remove control in the player to delete the selected track.
  5. Click Send to Export when the set is ready.

Common questions about Refine

If I remove a track in Refine, is the file deleted?

Can I hear a track before deciding?
Yes. Click a bar to load the track into the mini-player, then press play and scrub through it.

Local backups

Available Since 1.0.0 macOS

Local backups saves a copy of the USB stick's Engine library to the DJ's own computer before Alpha writes to the stick, so playlists can be restored if they are ever lost — for example after an Engine OS update clears the stick.

What Local backups does

Before writing a playlist to a stick that already has an Engine library, Local backups copies that library to the DJ's computer. The backup is kept on the local disk, not on the stick, so it survives even if the stick itself is wiped. Each backup is tied to the stick it came from, and an earlier version can be restored later.

How to use Local backups

  1. Write a set to a USB stick in the Export step. A backup of the stick's existing library is made automatically first.
  2. To restore, open the device's playlists and choose an earlier backup version.
  3. Confirm the restore to bring the earlier playlists back.

Local backups tooltips and on-screen text

Where it appearsExact wording in the app
Tooltip on a backup's restore controlRestore this version
Restore confirmation buttonRestore

What Local backups does not do

  • Local backups does not store the backup on the USB stick; it is kept on the DJ's own computer, so it survives a wipe of the stick.
  • Local backups does not copy the audio files; it backs up the Engine library (the playlists and their order).
  • Local backups does not upload anything; the backup stays on the DJ's computer.

Common questions about Local backups

An Engine OS update wiped my playlists — can I get them back?
If Alpha wrote to that stick before, a backup of its library was saved on the DJ's computer. Open the device's playlists and restore the earlier version.
Where is the backup stored?
On the DJ's own computer, not on the USB stick, so it is not lost if the stick is wiped.
Does Local backups back up my music files too?
No. Local backups saves the Engine library (playlists and order). The audio files are the DJ's own copies.

Match loudness

Available Since 1.0.0 macOS

Match loudness makes every track in a set play at the same perceived loudness (measured in LUFS), so the DJ never has to ride the gain between songs. Match loudness is set in the Refine step and written into the files during Export.

What Match loudness does

Match loudness measures each track's integrated loudness in LUFS (the EBU R128 / ITU-R BS.1770 standard) and its true peak while the track is analyzed. In the Refine step the DJ picks a target loudness, and the Refine mini-player then plays every track at that matched level so the DJ can hear the result. In the Export step, when Match loudness is ticked, Match loudness bakes a per-track gain into the copies written to the USB stick: a track quieter than the target is turned up, a louder one is turned down, so all tracks play at the same level on any device. Match loudness never raises a track's true peak above -1 dB, which prevents clipping.

How to use Match loudness

  1. Analyze the tracks — loudness is measured automatically during analysis.
  2. In the Refine step, keep Match loudness ticked and set the target with the slider, or click one of the reference points beneath the slider.
  3. Play a track in the Refine mini-player to hear it at the matched level.
  4. Go to the Export step and tick Match loudness (-14 LUFS) (the number shows the target).
  5. Click Write to USB. The write confirmation reports how many tracks were matched.

Match loudness on an imported library

When a library is imported from rekordbox (see rekordbox import), its loudness is not in the XML, so it has not been measured yet. In that case the Match loudness checkbox in Export is greyed out and cannot be ticked directly. Clicking it opens a short dialog, Match loudness before export?, which explains why and offers to measure the loudness now. The dialog has the same target slider and reference points (Apple Music / Streaming / Club / DJ Master) as Refine. Clicking Analyze & match loudness measures the loudness of exactly the tracks in the set, sets the chosen target, and then ticks the Export checkbox so the matched gain is baked in on write. Sets that were analyzed normally already have their loudness measured, so the checkbox is available without this step.

What Match loudness does not do

  • Match loudness does not change the DJ's original files. It applies the gain only to the copies written to the USB stick; the library files are untouched.
  • Match loudness does not add a compressor or a limiter and does not change a track's dynamics. Match loudness only changes the level (a gain adjustment).
  • Match loudness does not push a track above -1 dB true peak, so a quiet, highly dynamic track may stay a little below the target rather than clip.
  • Match loudness in Refine (the toggle and slider) only affects the mini-player preview. It changes no files. Only the Export checkbox writes the change into the files.
  • Match loudness does not read or reuse loudness or gain tags written by other DJ software; Match loudness bakes the level into the audio instead.

Common questions about Match loudness

Does Match loudness change my original files?
No. Match loudness applies the gain only to the copies written to the USB stick. The files in the DJ's library are not changed.
I ticked Match loudness in Export but the tracks are not louder — why?
The write confirmation may say not matched (loudness encoder unavailable). Match loudness needs the loudness encoder to bake the gain into the files; when it is not available the tracks are copied unchanged, so their loudness is not adjusted.
What target loudness should I choose?
-14 LUFS matches streaming (Spotify, YouTube, Tidal), -16 LUFS is Apple Music, and around -6 to -10 LUFS is louder, club-master territory. Consistency between tracks matters more than the exact number.
Why does one track stay quieter than the others?
Match loudness never lets a track's true peak exceed -1 dB. A quiet track with strong peaks reaches that ceiling before it reaches the target and stays a little below it.
Do I have to turn Match loudness on in both Refine and Export?
The Refine toggle controls what the DJ hears in the mini-player; the Export checkbox controls what is written to the stick. Tick the Export checkbox to bake the matched loudness into the exported files.
Why is the Match loudness slider in Refine greyed out?
The Match loudness toggle in Refine is off. Tick it to enable the target slider.
Why is the Match loudness checkbox in Export greyed out?
The set has no measured loudness — this happens with a library imported from rekordbox, where loudness is not in the XML. Click the greyed checkbox: the dialog Match loudness before export? offers to measure the loudness and match it right away, then enables the checkbox.

Skip duplicates

Available Since 1.0.0 macOS

Skip duplicates avoids re-copying tracks that are already on the USB stick: a track used in several playlists is stored once and every playlist links to that one file, which saves space and time.

What Skip duplicates does

When Skip duplicates is on, the Export step only copies tracks that are not already on the stick. If a track appears in several playlists, the file is stored once and each playlist links to it. The playlist order is written in full either way; Skip duplicates only affects whether the audio file is copied again.

How to use Skip duplicates

  1. In the Export step, find the Skip duplicates checkbox next to the write action.
  2. Leave it ticked (the default) to reuse files already on the stick, or untick it to copy every track again.
  3. Click Write to USB.

What Skip duplicates does not do

  • Skip duplicates does not leave tracks out of the playlist. The full order is always written; only the file copy is skipped when the file is already present.
  • Skip duplicates does not delete anything from the stick.
  • Skip duplicates does not change the DJ's original files.

Common questions about Skip duplicates

Will Skip duplicates leave songs out of my playlist?
No. The whole playlist order is written. Skip duplicates only avoids copying an audio file that is already on the stick; the playlist still links to it.
Should I turn Skip duplicates off?
Usually no. Leaving it on saves space and time. Turn it off only if you specifically want every track copied again.

USB export

Available Since 1.0.0 macOS

USB export writes the finished set to a Denon Engine DJ USB stick: it picks the controller format, copies the tracks with their interpreted metadata and playlist order, validates the result, and lets the DJ eject the stick safely. USB export is the last step, labelled 04 Export.

What USB export does

USB export writes a standard Engine OS 3.x library to the chosen USB stick: the audio files, the interpreted metadata (BPM, key), and the playlist order. It plays on any Denon hardware running Engine OS. Before writing to a stick that already has a library, USB export makes a local backup (see Local backups). After writing, USB export validates the result, and the DJ can eject the stick safely.

How to use USB export

  1. Confirm the target device / format (Denon, Engine OS 3.x).
  2. Check the playlist name, track count and duration.
  3. Choose whether Skip duplicates and Match loudness are ticked.
  4. Click Write to USB and wait for the confirmation.
  5. Use the eject control to unmount the stick before removing it.

Can I remove the stick as soon as writing finishes?

VirtualDJ export

Available Since 1.0.0 macOS

VirtualDJ export writes the finished set as a VirtualDJ library on the USB stick: a database.xml with every track's tags, BPM and key, plus an ordered playlist. It is one of the three formats in the 04 Export target picker.

What VirtualDJ export does

VirtualDJ export copies the audio to VirtualDJ/Music on the stick and writes a VirtualDJ/database.xml describing every track (artist, title, album, year, BPM, key, length) plus an ordered playlist under MyLists. VirtualDJ reads the key in Open Key notation, so Alpha converts each track's Camelot key to Open Key (for example A minor, Camelot 8A, is written 1m). Cover art is read from each file's tags, so it is not copied separately.

How to use VirtualDJ export

  1. Open the target device chooser and pick VirtualDJ.
  2. Check the playlist name, track count and duration.
  3. Click Write to USB and wait for the confirmation.
  4. Eject the stick, plug it into a computer running VirtualDJ, and load the library.

Which devices VirtualDJ export works with

VirtualDJ is software: the stick is loaded by the VirtualDJ app on a Windows or macOS computer, and any of VirtualDJ's supported controllers can then be used. It is not a standalone stick that plugs straight into hardware.

Common questions about VirtualDJ export

Does my key survive the export?
Yes. VirtualDJ uses Open Key notation (a number plus d for major or m for minor), so Alpha converts each track's Camelot key to Open Key — for example A minor (Camelot 8A) is written 1m.
VirtualDJ shows the set on a laptop but my CDJ does not — why?
VirtualDJ is computer software. For a stick that plays directly on Pioneer / AlphaTheta hardware, use the rekordbox export instead.

rekordbox export

Available Since 1.0.0 macOS

rekordbox export writes a Pioneer / AlphaTheta USB that CDJ and XDJ players read directly, with no rekordbox software needed. It is one of the three formats in the 04 Export target picker.

What rekordbox export does

rekordbox export writes a full rekordbox USB: the classic export.pdb library that every CDJ / XDJ has read for years, the newer encrypted exportLibrary.db that the latest players use, per-track analysis files (beat grid, cues and waveforms), album artwork, and the audio under Contents/<Artist>/<Album>. The beat grid is built from the interpreted BPM, so tracks arrive beat-ready. No rekordbox software is needed on the DJ's side.

How to use rekordbox export

  1. Open the target device chooser and pick Pioneer DJ / AlphaTheta / CDJ / XDJ.
  2. Check the playlist name, track count and duration.
  3. Click Write to USB and wait for the confirmation.
  4. Eject the stick, plug it straight into the player, and load the playlist.

Which devices rekordbox export works with

Standalone rekordbox players that read a USB directly — the stick plugs into the gear, no computer: CDJ-3000, CDJ-2000NXS2, XDJ-RX3 / RX2, XDJ-XZ, XDJ-1000MK2, XDJ-700, OPUS-QUAD and XDJ-AZ. This is a new target; please confirm it on your own player.

Common questions about rekordbox export

Do I need rekordbox installed?
No. Alpha writes the rekordbox library and analysis files itself, so the stick plays directly on a CDJ or XDJ.
Will it work on the newest players?
Alpha writes both the classic library (export.pdb) and the newer encrypted one (exportLibrary.db) that the latest players prefer. It is a new target, so please confirm on your own gear.
Are my cues and beat grid included?
Yes. Each track gets a beat grid (from the interpreted BPM), a waveform and any cues, written into the analysis files the player reads.

Playlists on device

Available Since 1.0.0 macOS

Playlists on device lets the DJ see and manage the playlists already on a connected USB stick — renaming or deleting them, and restoring an earlier backed-up version.

What Playlists on device does

Playlists on device reads the Engine library on the connected stick and lists its playlists. From there the DJ can rename a playlist, delete a playlist, or restore an earlier version of the library from a local backup (see Local backups). Deleting a playlist removes the playlist entry, not necessarily every audio file it referenced.

How to use Playlists on device

  1. With a stick connected, open the device's playlists (from the Analyze or Export step).
  2. To rename, use the rename control on a playlist, type the new name, and save.
  3. To delete, use the delete control and confirm.
  4. To restore an earlier version, choose a backup and confirm the restore.

Common questions about Playlists on device

I deleted a playlist by mistake — can I get it back?
If Alpha wrote to that stick before, restore an earlier version from a local backup (see Local backups).
Does deleting a playlist delete the songs?
Deleting a playlist removes the playlist entry. It does not necessarily remove every audio file the playlist referenced from the stick.
