The short version

Alpha writes drives for hardware running Engine DJ / Engine OS. We built and tested it on the Denon DJ Prime Go; the rest of the Engine OS family reads the exact same drive format.

Pioneer hardware is a different ecosystem: rekordbox keeps its library in an encrypted database, which is a separate problem from Engine OS. Those players aren't on the list yet — other formats are in the works, but Engine OS is what Alpha writes today.
