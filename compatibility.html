The short version

Alpha writes drives for hardware running Engine DJ / Engine OS. We built and tested it on the Denon DJ Prime Go; the rest of the Engine OS family reads the exact same drive format.

Pioneer hardware is a different ecosystem. rekordbox keeps its library in an encrypted database that we deliberately leave alone, so those players are not on the list — and won't be.
